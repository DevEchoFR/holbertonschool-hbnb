# HBnB Project

HBnB is a multi-stage accommodation booking project built at Holberton School. This repository contains the different milestones of the application, from the early design work to the REST API, authenticated backend, and frontend prototype.

## Overview

The project is organized into separate parts, each with its own README and dependencies:

- [part1](part1/) - early project material and design assets.
- [part2](part2/) - RESTful API built with Flask, Flask-RESTx, and an in-memory repository.
- [part3](part3/) - authenticated backend with JWT, role-based access, and SQLAlchemy persistence.
- [part4](part4/) - frontend prototype with HTML, CSS, JavaScript, and a lightweight Flask app.

## What the project covers

- User management and authentication
- Places, amenities, and reviews
- API design with layered architecture
- Persistent storage in the later backend stages
- A browser-based interface for browsing places and logging in
